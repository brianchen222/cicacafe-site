咖啡豆推薦怎麼選？用心情與風味顏色，3 步找到你的那一支

選咖啡豆先問三件事：你怎麼喝（義式機、手沖還是濾掛）、想要什麼風味（明亮果酸、濃郁醇厚，或草本清爽）、以及看烘焙日期而非有效期限。CICACAFE 的作法是——不用背產地與處理法，用「心情與風味顏色」選：橘紅的熱烈、乳白的溫柔、花果的明亮，一眼找到你的那一支。

1. 先問你怎麼喝：義式／手沖／濾掛

同一支豆，換一種沖法就是兩種味道。先決定沖煮方式，選豆才有方向。

  • 義式咖啡機／全自動機：選中焙到中深焙的義式拼配，醇厚、有 body，牛奶也壓得住。CICACAFE 的城市生活系列與銀河金獎豆都屬這一類。
  • 手沖：選單一產區、風味乾淨明亮的豆，喝層次。研磨度與義式不同，建議挑「手沖專屬」的豆。
  • 濾掛：想省事又不將就的人。濾掛 10g 用的是和 250g 同一支的金獎豆，只是換一個更方便的入口。

2. 焙度決定風味走向

焙度是最快抓到方向的指標。愈淺愈酸香明亮、愈深愈濃郁苦甜：

焙度風味走向適合
淺／中焙花香、果酸、明亮手沖、愛果汁感的人
中焙均衡、堅果、奶油甜每天都喝、不挑人
中深焙巧克力、焦糖、醇厚義式、加奶、冰飲
深焙濃郁、煙燻、低酸喚醒一天的第一杯

不知道自己喜歡哪種？先從「中焙均衡」開始最安全，再往明亮或濃郁兩邊試——這也是為什麼綜合試喝組是最好的起點。

3. 用風味顏色與心情選

產地、處理法、杯測分數，是給咖啡師看的語言。CICACAFE 把風味翻成顏色與心情——因為你感受到的顏色，就是這支豆想告訴你的一切。火星是橘紅的熱烈能量、金星是乳白帶淡黃的溫柔、獵戶座是紫紅的花果星雲。你不需要懂咖啡，只需要知道今天想要什麼感受。

4. 看烘焙日期，不是有效期限

咖啡豆不是愈久愈香。烘焙日期才是關鍵——新鮮烘焙、養豆幾天後風味最好，開封後建議一個月內喝完。看到只標「有效期限」卻沒有「烘焙日期」的，要小心。CICACAFE 每支豆都由 2018 世界盃烘豆大賽台灣區烘豆師新鮮烘焙。

5. 獎項與認證代表什麼

獎項是別人幫你先試過的信任狀。IIAC 國際咖啡品鑑金獎由義大利的國際評審團盲測評分，代表這支豆在風味品質上通過國際標準。CICACAFE 銀河系列已拿下 2024、2025 多面 IIAC 金獎——想送禮或想一次到位，從金獎豆開始最不會錯。

選豆常見地雷

  1. 只看價格，不看沖煮方式再好的手沖豆，丟進義式機也不對味。先對到你的器材。
  2. 只有有效期限、沒有烘焙日期看不到烘焙日期，通常代表放很久了。
  3. 一次買太多咖啡是生鮮，開封後風味遞減。寧可少量常買。
  4. 被術語勸退不用先懂產地與處理法——從心情與焙度入門就夠了。

常見問題

咖啡豆和濾掛哪個好？

看你想省多少事。要器材、想玩沖煮就選豆（250g）；只想撕開沖水就選濾掛（10g）。CICACAFE 濾掛用的是和豆同一支的金獎豆，方便但不將就。

新手第一支咖啡豆推薦？

從「中焙、均衡」的豆或綜合試喝組開始最安全，喝過再往明亮或濃郁調整。

義式咖啡豆和手沖豆差在哪？

義式偏中深焙、講究醇厚與 body，適合機器高壓萃取；手沖偏乾淨明亮、喝層次，研磨度也不同。買前先確認豆是為哪種沖法優化的。

咖啡豆開封後怎麼保存？

密封、避光、常溫陰涼處，避免冰箱受潮。開封後建議一個月內喝完，風味最好。

怎麼知道豆夠新鮮？

看包裝上的「烘焙日期」而非有效期限；沖煮時粉會膨脹（悶蒸鼓起）也是新鮮的指標。
